How these get made on a 16 GB laptop
The local model never draws the picture. It reads the cited emails and fills in a small structure: the events for a timeline, the people and counts for a map, the decisions for a table, the outline for a brief. The library then renders that structure into SVG, Word, Excel or Markdown from a template, so the output is always well-formed, in a consistent style, and every item keeps its source email. A free-form "write me a …" request produces Markdown you can edit, and the Word export is made from that.
